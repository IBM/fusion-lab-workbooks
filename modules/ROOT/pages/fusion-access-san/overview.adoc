== Introduction

**IBM Fusion Access for SAN** (powered by **IBM Storage Scale Container Native Storage Access (CNSA)**) provides high-performance, low-latency block storage access for Red Hat OpenShift Virtualization workloads over Fibre Channel (FC) or iSCSI protocols.

== Key Capabilities

* **Easy User Experience:** Wizard-driven user interface to install and configure storage clusters, file systems, and storage classes.
* **Use Existing Infrastructure:** Leverage existing SAN investments, including Fibre Channel (FC) and iSCSI technologies, as you transition to or expand with OpenShift Virtualization.
* **Scalability:** Storage cluster designed to scale with OpenShift Container Platform clusters and virtual machine workloads. Supports up to approximately 3000 VMs on 6 bare-metal hosts.
* **Consolidated and Shared Storage:** Multiple servers access large, shared data storage capacity with automatic data backup and continuous monitoring.
* **High-Speed Data Transfer:** Dedicated high-speed network for storage overcomes data transfer bottlenecks of traditional LAN.
* **File-Level Access:** File systems built on top of SAN storage provide file-level access through shared-disk file systems.
* **Centralized Management:** Centralized management and configuration of SAN components like Logical Unit Numbers (LUNs).

== Architecture

IBM Fusion Access for SAN is based on **IBM Storage Scale Container Native Storage Access (CNSA)** using local filesystems. The architecture uses IBM Storage Scale as a containerized clustered file system that provides concurrent access from multiple nodes.

IBM Storage Scale CNSA deploys as:
* **Core pods** on selected worker nodes (storage nodes)
* **CSI driver** with operator, CSI sidecars, and CSI node plugins
* **Local filesystems** backed by shared LUNs accessible by all worker nodes simultaneously

== Use Cases

* High-performance, low-latency storage for OpenShift Virtualization VMs
* Migrating VMware workloads to OpenShift Virtualization with comparable storage performance
* Enterprise storage abstraction independent of underlying storage vendor
* OpenShift-native user interface for storage management
